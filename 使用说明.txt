notchplayer — 免费试用版 0.2.73

安装
1. 打开 notchplayer 的 DMG，把 notchplayer.app 拖入 Applications（应用程序）。
2. 从应用程序打开 notchplayer，会显示设置窗口；关闭设置后，它会在后台等待播放。设置窗口打开时显示 Dock 图标。
3. 免费试用包使用本地签名，尚未经过苹果公证。如果 macOS 提示开发者无法验证，请先确认下载来自 thorpjia-cloud/notchplayer，再按苹果官方流程：系统设置 → 隐私与安全性 → 仍要打开。无需终端命令，也不要关闭 Gatekeeper。
4. 首次播放时允许“系统音频录制”，用于本地实时频谱分析。音频不保存、不上传，不使用麦克风。若拒绝，播放控制仍可用，波形无法显示；之后在系统设置中允许，再右键顶部面板 → 重新连接播放器。

再次启动与登录自启动
在 Finder 的“应用程序”里双击带刘海与波形图标的 notchplayer，即可打开设置；没有播放音乐时也能打开。
在 notchplayer 设置中勾选“开机自启动”，登录 Mac 后会在后台运行，播放音乐时再显示；取消勾选即可关闭。开关直接读取系统登录项状态，无需重复添加。若系统要求允许，点击设置中的“打开系统登录项设置”完成确认。

要求
- macOS 14 或更新；真实频谱需要 macOS 14.2 或更新。
- Apple Silicon 和 Intel 的通用安装包；当前已在 Apple Silicon Mac 实机验证，Intel 分支通过 Rosetta 启动检查，未在 Intel 实机验证。
- 原生 Liquid Glass 需要 macOS 26 或更新；旧系统使用兼容玻璃效果。

播放
先在音乐软件中播放歌曲，封面和波形会从刘海两侧柔和浮现。把鼠标移到屏幕顶部中央，轻微放大后点击展开；移开约半秒收起。
暂停、切歌、切换到其他应用或关闭播放器窗口时，面板继续保留；退出当前播放器进程后自动隐藏。再次播放会自动显示收起状态。
面板可播放/暂停、切换上一首下一首、调整进度和系统音量。长歌名、歌手和专辑名会自动滚动。
展开后点击硬件刘海左侧的设备图标，可查看当前声音输出（带勾选标记），并在 Mac 扬声器、已连接蓝牙耳机等系统输出之间切换。音量控件跟随设备更新；菜单底部可打开系统声音设置。
右键面板可打开设置、检查更新、查看说明、重新连接播放器或退出。

菜单栏外观
默认跟随菜单栏深浅外观：深色使用黑色渐变，浅色让顶部与展开面板连续显示玻璃。可在设置的“外观 → 菜单栏样式”里固定为“黑色渐变”或“统一玻璃”，重启后保留选择。动态壁纸按系统提供的预览图判断明暗，必要时可手动固定样式。

网易云音乐
必须在网易云音乐的“设置 → 常规 → 播放歌曲时”勾选“启用系统歌曲播放通知栏”。
此选项关闭时，网易云不会提供完整的系统歌曲信息，notchplayer 无法检测并显示新的音乐会话。

其他播放器
跟随 macOS 当前的“正在播放”来源。已实测 Apple Music，以及开启上述选项的网易云音乐 3.1.13。
其他应用的封面、进度和控制支持取决于其系统媒体接口；当前没有手动选择播放器的功能。
蓝牙、HDMI 等设备若不支持系统音量调节，音量滑块会禁用。

更新与卸载
更新：设置中的“自动检查更新”会每天检查 GitHub 正式版本并直接下载，准备完成后点击“重启并更新”。也可点击“检查更新”立即检查。0.2.66 及更早版本需手动安装一次新版。
卸载：右键面板退出，将应用程序中的 notchplayer.app 移到废纸篓。
