# Third-party dependency

`Vendor/mediaremote-adapter` contains the source of [ungive/mediaremote-adapter](https://github.com/ungive/mediaremote-adapter), pinned to commit `797729d9b16316dc313844476c153d7a107ca0df`.

The original BSD-3-Clause license is included at `Vendor/mediaremote-adapter/LICENSE`. The dependency source is included in this backup so a normal clone contains everything required by `build.sh`; no submodule initialization is needed.

`Vendor/Sparkle` contains the official [Sparkle 2.10.0](https://github.com/sparkle-project/Sparkle/releases/tag/2.10.0) binary distribution, pinned by SHA-256 in `Tools/prepare-sparkle.sh`. Sparkle provides signed feed validation, update archive verification, download, replacement and relaunch. Its original license is in `Vendor/Sparkle/LICENSE` and is bundled with the app.
