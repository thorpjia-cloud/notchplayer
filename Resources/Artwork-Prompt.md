# 光痕背景生成记录

工具：内置 image_gen；模式：编辑透明光痕素材，扩大覆盖面积并增加光学层次。配色与运动方向参考用户提供的蓝橙摄影图；人物与原始场景未包含在图标中。

最终资源：`AppIcon.icon/Assets/00-light-trails.png`。刘海与波形为独立 SVG 图层；底色使用原生浅色与深色外观，波形的玻璃材质在 Icon Composer 中配置。
